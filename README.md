DiRT
===

Dietary Restrictions Tracking App for Teams

[Live demo here](https://dirt-91js.onrender.com/)


## Features

1. Signup/login/logout
2. Create surveys
3. Delete surveys
4. Filter/fix ambiguous variations of dietary restrictions
5. Anonymous responses
